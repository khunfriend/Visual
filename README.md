# ข้อเสนองบเขตดินแดง (PerVis Project)

เว็บสไลด์นำเสนอขอเพิ่มงบประมาณเขตดินแดง สร้างด้วย Vite + React + Recharts ไม่มี backend

- เว็บที่ deploy: https://khunfriend.github.io/Visual/
- วิชา 2603-278 สารสนเทศวิทัศน์ ภาคต้น 2569

## เริ่มใช้งาน

```bash
npm install
npm run dev       # เปิดที่ http://localhost:5181
```

| คำสั่ง | ทำอะไร |
|---|---|
| `npm run dev` | เปิดเว็บในเครื่องสำหรับแก้งาน |
| `npm run build` | สร้างไฟล์เว็บไว้ในโฟลเดอร์ `dist/` สำหรับ deploy |
| `npm run preview` | เปิดดูไฟล์ที่ build แล้ว (ใช้ตอนไม่มีเน็ต) |
| `npm run data` | สร้างข้อมูล `src/data/*.json` จาก `data/raw/` พร้อมตรวจตัวเลขหลัก |
| `npm run map` | สร้างข้อมูลแผนที่ `src/data/map.json` |

**ปุ่มตอนนำเสนอ:** ←/→ เปลี่ยนหน้า · พิมพ์เลขแล้ว Enter เพื่อกระโดด · F เต็มจอ · `?only=3` ดูหน้าเดียว

## แก้งานอย่างไร

- **แก้หน้าเดียว:** แตะเฉพาะไฟล์ในโฟลเดอร์ของหน้านั้น แล้วเปิด `?only=เลขหน้า` ดูผล
- **เปลี่ยนตัวเลข:** แก้ `ข้อมูลรวม_ตรวจแล้ว.md` ก่อน แล้วแก้ `data/scripts/build_data.py` และรัน `npm run data` ห้ามแก้ JSON ใน `src/data/` ด้วยมือ
- **เปลี่ยนสี:** แก้ที่ `src/theme/theme.js` ห้ามเขียนรหัสสีตรง ๆ ในสไลด์
- **แก้ `components/` `deck/` `theme/`:** มีผลทุกหน้า แก้แล้วต้องเปิดดูทุกหน้า
